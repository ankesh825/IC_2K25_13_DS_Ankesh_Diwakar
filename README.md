## Time Complexity — Basic Overview

| Data Structure | Operation | Time Complexity |
|---|---|---|
| Array | Access by Index | O(1) |
| Array | Linear Search | O(n) |
| Stack | Push | O(1) |
| Stack | Pop | O(1) |
| Queue | Enqueue | O(1) |
| Queue | Dequeue | O(1) |
| Singly Linked List | Traversal | O(n) |
| Singly Linked List | Insertion at Beginning | O(1) |
| Singly Linked List | Searching | O(n) |

**Note:** These are standard complexities for the specified operations and implementations.
